OELTKit turns LLM-generated learning content into accessible, SCORM- and cmi5-compliant courses. These docs cover the five-minute quickstart, the authoring model, tracking across LMS standards, every interaction component, and how to connect the toolkit to your AI assistant.

:::caution[Beta docs]
The toolkit is pre-v1.0 and these docs are drafts. Anything marked **TODO** is pending the specs in the [main repository](https://github.com/oeltkit/oeltkit) — it is deliberately not filled in with guesses.
:::

## Start here

- **[Quickstart](quickstart/)** — install → `oelt new` → chat → `oelt package`, in five minutes.
- **[Authoring guide](authoring-guide/)** — how the free-form content layer and OELTKit's components fit together.
- **[Tracking guide](tracking-guide/)** — one tracking API, four LMS targets, and the SCORM 1.2 collapse rule.
